# macOS 远程客户端

`ETF远程监控.app` 是只读内网客户端，不包含 Wind、LLDB、TBAPI 探针或主机服务。

首次启动默认显示 `192.168.1.113:6787`，但不会自动连接。点击红色“未连接”按钮后建立连接，连接成功会变为绿色。服务器地址、端口、自动重连、声音、重复次数、弹窗时间和外部音频都可以在“设置”中修改。

客户端连接后先获取全量快照，随后通过 WebSocket 接收变化主推。申购/赎回金额不显示，也不参与变化判断；告警只依据申购份额和赎回份额。双击标的可查看由 Mac-home 提供的 PCF 详情。

列表中的“申购额度”由客户端本地计算：累计申购份额对比 PCF 的 `CreationLimit`，轧差份额对比 `NetCreationLimit`，任一达到即显示红色“已满”。仅净申购限额会因盘中赎回而重新释放。

名称由 Mac-home 主机维护并自动同步；远程客户端只读显示。主机本人可双击标的打开 PCF 详情，在“自定义名称”中修改并保存。

主页的“申购篮子/赎回篮子”由实时份额除以 PCF 最小申购赎回单位得出，不使用 Wind 笔数。份额按四位分组显示，例如 `1000000` 显示为 `100 0000`。

主页同时显示轧差篮子（轧差份额 ÷ PCF 最小单位）。服务器 IP 和端口改到“设置”中维护，远程客户端不再显示无操作价值的观察列表栏。变化弹窗和横幅会同时显示标的代码与名称。

安装方法：解压 `ETF远程监控-macOS-arm64.zip`，将 `ETF远程监控.app` 拖入“应用程序”文件夹。当前构建适用于 Apple Silicon Mac，最低支持 macOS 13。
