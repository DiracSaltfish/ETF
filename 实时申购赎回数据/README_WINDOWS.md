# Windows 远程客户端源码

Windows 设备只运行只读远程客户端，不需要 Wind、lldb 或探针。它通过内网连接 Mac-home 的 `6787` 端口，默认由用户点击红色连接按钮后才连接，并在已发起连接后自动处理意外断线重连。连接后先收到全量快照，之后只接收 WebSocket 主推；不能开始/停止主机监控、修改观察列表或刷新 PCF。收到份额变化时，弹窗和声音都在 Windows 本机触发。

客户端首页显示盘中反向申赎得到的“盘中申购机会/盘中赎回机会”判断，不再占用列展示 PCF 日期和最小单位；更新时间仅显示本地 `HH:MM:SS`。双击任一标的仍可从主机读取 PCF 摘要与成分证券明细；PCF 的网络拉取和日期缓存都发生在 Mac-home，Windows 不会直接访问交易所接口。

“申购额度”列在 Windows 客户端本地同时检查 PCF 的累计申购上限 `CreationLimit` 和净申购上限 `NetCreationLimit`，任一达到即显示红色“已满”；仅净申购限额会因盘中赎回而重新释放。PCF 尚未就绪时显示灰色“待确认”。

标的名称由 Mac-home 主机在 PCF 详情页手动维护，并随服务端快照/推送同步到 Windows；Windows 客户端保持只读，不能修改名称。

主页的“申购篮子/赎回篮子”由实时份额除以 PCF 最小申购赎回单位得出，不使用 Wind 笔数。份额按四位分组显示，例如 `1000000` 显示为 `100 0000`。

主页同时显示轧差篮子（轧差份额 ÷ PCF 最小单位）。服务器 IP 和端口改到“设置”中维护，远程客户端不再显示无操作价值的观察列表栏。变化弹窗和横幅会同时显示标的代码与名称。

客户端启动后默认不连接服务端，红色“未连接”按钮点击后才发起连接；连接成功后按钮自动变绿，点击绿色按钮即可断开。“设置”菜单可以配置服务器 IP/主机名与端口、启动自动连接、重连间隔和心跳间隔。变化提醒支持 5 种内置原创提示音、立即试听、本机外部音频、音量、弹窗停留时间与提醒冷却。可设置重复 1～10 次，“轻亮三音”默认重复 3 次，共 9 响。冷却只抑制连续弹窗和声音，不会漏掉表格更新。首次全量数据自动作为基准，之后发生变化的标的整行持续高亮，直到点击“重置变化基准”；右下角横幅会显示最新变化 60 秒，也可手动关闭。

## 直接运行源码

将本目录中的以下文件和资源目录复制到 Windows 的同一文件夹：

- `etf_remote_client.py`
- `requirements-windows-client.txt`
- `启动Windows客户端.bat`
- `打包Windows客户端.bat`
- `assets\sounds\`（内置提示音）

安装 Python 3.10 或更高版本后，双击 `启动Windows客户端.bat`。脚本会自动创建 `.venv` 并安装 PyQt6。界面内输入 Mac-home 的地址，例如 `192.168.1.23:6787`。

## 打包 EXE

双击 `打包Windows客户端.bat`。产物位于：

```text
dist\ETF远程监控\ETF远程监控.exe
```

这是 `onedir` 版本，启动快且更容易排查依赖；分发时复制整个 `dist\ETF远程监控` 文件夹。打包必须在 Windows 上执行，不能用 Mac 交叉生成 Windows EXE。

## 网络条件

- Windows 与 Mac-home 必须能互相访问内网 IP。
- Mac-home 的系统防火墙需允许 `ETF监控主机` 接收入站连接。
- 服务按需求不使用令牌或实名验证，因此不要把 `6787` 映射到公网。
