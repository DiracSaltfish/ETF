# 四类股指期货滚贴水模型

本目录用于回测 IF（沪深300）、IH（上证50）、IC（中证500）和 IM（中证1000）的主力合约滚贴水策略。原始数据只读来自 `/Volumes/Stocksdata`，生成结果全部写入本目录的 `outputs/`。

## 业务与盈利模式

这里的“滚贴水”定义为：以 1 倍名义本金持续做多股指期货主力合约，在主力代码改变时平旧开新。基差用对应价格指数计算，策略业绩则与含现金分红再投资的税前全收益指数比较。

期货理论价格可写为 `F = S × exp((r-q)T)`。当期货低于现货（贴水）时，只要到期前基差向 0 收敛，做多期货相对持有现货可能获得正的基差收益。完整收益来源是：

`期货总收益 = 指数方向收益 + 基差变化/收敛收益 + 展期后的新基差机会 + 现金收益 - 手续费 - 滑点`

重要的是，换月时远月与近月的价格差不是立即落袋的会计利润。真正的收益来自持有新合约后基差向交割价收敛。因此本模型不会把主连切换产生的价格跳变直接计入收益。

## 四类合约与业务约束

| 代码 | 标的指数 | 合约乘数 | 最小变动价位 | 最低交易保证金 |
|---|---|---:|---:|---:|
| IF | 沪深300 | 300元/点 | 0.2点 | 合约价值8% |
| IH | 上证50 | 300元/点 | 0.2点 | 合约价值8% |
| IC | 中证500 | 200元/点 | 0.2点 | 合约价值8% |
| IM | 中证1000 | 200元/点 | 0.2点 | 合约价值8% |

四个品种的合约月份均为当月、下月及随后两个季月，最后交易日为到期月份第三个周五并采用现金交割。交易所最低保证金不是账户实际保证金，券商通常会在此基础上加收；生产模型必须使用真实账户参数。

## 回测口径

- 每日取 15:00 或之前的最后一分钟收盘价，使期货与现货尽量同刻。
- 基差 `F/S-1` 使用价格指数：000300、000016、000905、000852。
- 业绩基准使用中证官方税前全收益指数：H00300、H00016、H00905、H00852。
- 同一合约期间用真实期货收盘价变化计算收益。
- 主力合约切换日因缺少新旧合约同刻报价，用当日现货指数收益替代主连跳变；从下一交易日起继续使用新合约的真实收益。
- 基准情景使用 1 倍名义敞口、现金收益 0%、交易所非平今费率 `0.000023`、每边 0.2 指数点滑点。
- 首次开仓、每次换月的平旧开新、样本末平仓都计成本。
- 所有假设可在 `config.yaml` 修改。

全收益数据更新：

```bash
conda run -n ag python scripts/fetch_total_return_indices.py --config config.yaml
```

## 数据限制

当前期货库只保存每分钟的主连合约及当时合约代码，没有保存所有可交易月份的并行行情。因此当前版本能够真实核算“历史主力路径”的净收益，但不能回答“每天在四个到期月份中选择贴水最深者”是否更优，也无法用同刻盘口精确测量每次换月价差。`outputs/roll_events.csv` 保留了主连切换跳变作为诊断字段，但该字段不作为收益。

此外，主力合约的选择规则由数据提供方决定；如果其规则使用了当日收盘后的成交量，可能存在不可交易的事后识别偏差。要做生产级验证，需要补充全合约逐分钟行情、买一卖一、实际券商费率、账户保证金利息和真实成交回报。

主要输出：

- `outputs/summary.csv`：四品种全样本汇总
- `outputs/annual_returns.csv`：年度收益与超额
- `outputs/daily_returns.csv`：逐日净值、基差、成本和回撤
- `outputs/individual/{IF,IH,IC,IM}_daily.csv`：四个品种各自独立的逐日收益测试
- `outputs/individual/{IF,IH,IC,IM}_summary.csv`：四个品种各自独立的汇总指标
- `outputs/charts/{IF,IH,IC,IM}_return_test.png`：分别与对应全收益指数比较的净值及回撤图
- `outputs/roll_events.csv`：逐次主力切换诊断
- `outputs/sensitivity.csv`：成本与现金收益敏感性
- `outputs/data_quality.json`：源数据覆盖与质量检查
- `outputs/validation_report.md`：独立复核结果与必须披露的限制
- `outputs/report.html`：最终可阅读报告
- `滚贴水回测.ipynb`：已执行、可从头复现的分析笔记本
